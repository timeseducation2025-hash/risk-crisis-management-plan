# 🚀 دليل نشر منصة إدارة المخاطر والأزمات على الدومين

## المتطلبات
- استضافة تدعم PHP 7.4+ وMySQL (أي استضافة cPanel عادية — Hostinger / GoDaddy / Naby / nserv...)
- دومين مثل: egga-fayoum.com

## خطوات الرفع (10 دقائق)

### 1) رفع الملفات
- ادخلي cPanel ← File Manager ← مجلد `public_html`
- ارفعي ملف `egga-platform.zip` وافكّيه — يجب أن يصبح:
  - `public_html/index.html` (المنصة)
  - `public_html/admin.html` (لوحة الإدارة)
  - `public_html/api/...` (الخادم)

### 2) إنشاء قاعدة البيانات
- cPanel ← MySQL Databases:
  - أنشئي قاعدة: `egga_platform`
  - أنشئي مستخدم: `egga_user` بكلمة مرور قوية ← أضيفيه للقاعدة بكل الصلاحيات

### 3) ربط الخادم بالقاعدة
- عدّلي الملف `api/config.php` ببيانات القاعدة الجديدة + غيّري `SECRET` + ضعي رقم واتسابك في `WA_ADMIN`

### 4) التثبيت
- افتحي في المتصفح: `https://your-domain.com/api/install.php`
- سترين رسالة نجاح — **احذفي ملف install.php فورًا** ✔

### 5) أول دخول
- لوحة الإدارة: `https://your-domain.com/admin.html`
- البريد: `admin@egga-egypt.org` — كلمة المرور: `EgGa@Fayoum2026` ← **غيّريها من قاعدة البيانات أو أعيدي إنشاءها**
- من لوحة الإدارة: أضيفي أدمن فرعي، ولّدي أكواد الأجهزة والحسابات، وتابعي سجل الدخول

## آلية التشغيل اليومية
1. المستخدمة تفتح الدومين ← يظهر لها رقم تعريف جهازها ← تنسخه وترسله واتساب
2. أنتِ (من admin.html على أي جهاز/موبايل) تلصقين الرقم ← توليد كود ← ترسلينه له
3. تدخل الكود ← يتفعل الجهاز ← تسجل حسابها ← تطلبين كود حساب ← تدخله ← تشتغل

## ⚠️ ملاحظات مهمة
- المنصة الآن **مركزية**: كل المستخدمين والأكواد والسجلات في قاعدة بياناتك — لا يمكن تزوير الأكواد من المتصفح
- أرشيف التقارير يُحفظ محليًا على جهاز كل مستخدمة + تصدير/استيراد JSON للتجميع
- احصلي على شهادة SSL مجانية (Let's Encrypt من cPanel) ليعمل https
